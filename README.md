# 🔬 세균 돋보기 (Germ Lens)

카메라로 손, 얼굴, 입속을 비추면 꼬물꼬물 움직이는 세균이 나타나는 **유아 위생 교육용 웹페이지**입니다.
눈에 보이지 않는 세균을 눈으로 보여 주어, 아이들이 손 씻기·세수·양치 습관을 즐겁게 익히도록 돕습니다.

👉 **바로 사용하기: https://mignon0814.github.io/germ-lens/**

---

## ✨ 기능

- **자동 인식**: 버튼을 고를 필요 없이 화면에 보이는 부위를 알아서 찾습니다.
  - ✋ 손 (양손까지)
  - 🙂 얼굴 (눈과 입술은 피해서 표시)
  - 🦷 입속 (입을 "아~" 벌리면 나타남)
- **꼬물꼬물 세균**: 바이러스, 막대균, 알갱이균, 나선균이 몸을 따라 움직이며 기어다닙니다.
- **🧼 씻고 왔어요**: 씻고 와서 누르면 세균이 톡톡 터지며 사라집니다. 다시 누르면 세균이 다시 나타납니다.
- **📸 멈춤**: 화면을 멈춰서 자세히 볼 수 있습니다. 사진은 저장되지 않습니다.
- **🔄 카메라 전환**: 앞/뒤 카메라를 바꿉니다.

## 📱 사용 방법

1. 위 링크를 크롬 브라우저로 엽니다.
2. **시작하기**를 누르고 카메라 권한을 **허용**합니다.
3. 손바닥이나 얼굴을 카메라에 보여 줍니다. 입을 크게 벌리면 입속 세균도 보입니다.
4. 아이와 함께 손을 씻고, 세수하고, 양치를 하고 옵니다.
5. 오른쪽 위 **🧼 씻고 왔어요**를 눌러 세균이 사라지는 걸 확인합니다.

## 🔒 개인정보

- 로그인, 회원가입, 앱 설치가 필요 없습니다.
- 카메라 영상은 **기기 안의 브라우저에서만 처리**되며, 저장하거나 서버로 보내지 않습니다.
- 서버나 데이터베이스가 없는 정적 웹페이지(HTML 파일 1개)입니다.

## ⚠️ 알아 두세요

- 실제 세균을 촬영하거나 검출하는 것이 **아닙니다**. 눈에 보이지 않는 세균이 있다는 것을 보여 주는 **교육용 시뮬레이션**입니다.
- 카메라는 **https 주소**에서만 작동합니다. 파일을 내려받아 쓸 경우 PC 크롬에서 더블클릭해 열면 됩니다.
- 처음 열 때 인식 모델을 내려받느라 몇 초 걸리며, 인터넷 연결이 필요합니다.
- 오래된 기기에서는 세균이 조금 늦게 따라올 수 있습니다.

## 🛠️ 사용 기술

- [MediaPipe Tasks Vision](https://developers.google.com/mediapipe/solutions/vision/hand_landmarker): Hand Landmarker(손), Face Landmarker(얼굴·입)
- HTML Canvas 2D: 세균 그리기와 애니메이션
- `getUserMedia`: 카메라

## ⚙️ 설정 바꾸기

`index.html` 위쪽의 값을 바꾸면 됩니다.

| 항목 | 위치 | 설명 |
|---|---|---|
| 손 세균 크기 | `HAND_GERM_SIZE` | 작게 0.03 ~ 크게 0.06 |
| 세균 개수 | `CONFIG` 의 `count` | 손 / 얼굴 / 입속 각각 |
